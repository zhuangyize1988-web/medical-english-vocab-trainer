# 医学考博单词训练小程序

在线学习地址：<https://zhuangyize1988-web.github.io/medical-english-vocab-trainer/>

GitHub Pages 版本可在外网直接使用，学习记录默认保存在当前设备浏览器中；跨设备同步仍需在线同步服务。

双击 `start-local.bat` 后即可使用。它会先在后台启动服务，再打开 `http://127.0.0.1:8787/`；手机与电脑连接同一 Wi-Fi 时，可使用电脑的局域网地址访问。

## 功能

- 英译中
- 中译英
- 听音选词
- 英文题目自动发音
- 可选择浏览器/系统英语发音音色
- 答对后自动进入下一题
- 每天固定新增 50 个未学新词
- 新词之外，先复习前一天全部错词，再复习既往高优先级错词 20 个
- 当天 50 个完成后自动复习今日错词
- 长期错词记录：保存错误次数、连续答对次数、难度和下次复习时间
- 每个错词长期保存词根、词缀、同义词、易混词或真题语境记忆点，再次出现时显示在主界面
- 1049 个词均配有新版记忆点；词根只采用可靠拆解，多义词优先使用医学搭配和真题义项
- 按遗忘规律安排复习；错误越多出现越频繁，连续多次答对后才标记熟练
- 当天错词必须循环到答对，并在第二天继续出现
- 每日错词由 Codex 大模型生成独立语境完形；每题含完整中文翻译、答案解析和四个选项辨析
- 每天 1 条医学句子仿写 + 5 个写作核心词
- 本机记忆进度与同步服务器长期记录
- 电脑与手机通过同步码共享学习进度
- 页面打开、切回前台及每30秒自动检查新进度
- CSV/JSON 导入词库

## 手机与电脑同步

1. 电脑在“更多设置”中点击“生成”，记下同步码。
2. 手机打开同一个学习地址，在“更多设置”中输入同步码并点击“连接同步”。
3. 此后单词进度、今日错词和写作记录会自动保存并同步。

## 导入 CSV

```csv
word,meaning,category,example
diagnosis,诊断,医学核心词,The diagnosis was confirmed by a blood test.
```

```json
[

    "word": "diagnosis",

    "category": "医学核心词",
    "example": "The diagnosis was confirmed by a blood test."
  }
]
```
